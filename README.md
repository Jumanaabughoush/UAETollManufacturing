# MicroSynergy Project Dashboard

Static dashboard for UAE toll manufacturing. The public copy includes an empty `projects.json` placeholder.

Run `python -m http.server 8000` from the repository root and open `http://localhost:8000`.

To publish on GitHub Pages, select `main` and `/ (root)` under Settings → Pages.
